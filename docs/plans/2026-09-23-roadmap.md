## Правила для всех итераций

- TDD: сначала падающий приёмочный тест (HTTP + Testcontainers), затем внутренний цикл red→green→refactor (домен/application), затем адаптеры.
- Ветки `feat/iteration-N-<тема>`; Conventional Commits; тесты коммитятся вместе с реализацией или раньше.
- Каждая итерация: зелёный `./mvnw verify` (unit + application + контрактные + IT + ArchUnit + JaCoCo gate).
- Новые понятия сначала в `docs/domain/glossary.md`, затем в код.
- Изменения правил — сначала в docs (context map, aggregates.md, ADR), затем код.
