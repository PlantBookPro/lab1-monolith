# Глоссарий единого языка

Названия классов, методов, событий, таблиц, эндпоинтов и тестов берутся отсюда.
Новое понятие сначала сюда, затем в код. При расхождении кода с глоссарием
правится глоссарий (или код — по решению ADR), затем реализация.

Источник: `docs/requirements.md`, раздел 4.1 (дополняется по мере появления понятий).

| Термин (RU) | Термин в коде | Контекст-владелец | Смысл |
|---|---|---|---|
| Пользователь, учётная запись | `User` | identity | Субъект с ролями, профилем и координатами |
| Изображение, файл | `MediaAsset` | media | Неизменяемый загруженный файл и его метаданные |
| Отпечаток изображения | `ImageFingerprint` | media (публикует), plants (использует) | Хэш нормализованных пикселей с версией алгоритма |
| Хранилище файлов | `FileStorage` | media | Порт хранения байтов: локальный volume в лабе №1, file-service/S3 в лабе №4 |
| Растение, экземпляр растения | `Plant` | plants | Заявка «это моё растение» на конкретном изображении; может погибнуть |
| Гибель | `Plant.die(...)` / `PlantDied` | plants | Необратимый переход ALIVE → DEAD |
| Запрет изображения | `ImageRestriction` | plants | PERMANENT или COOLDOWN для пары (владелец, отпечаток) |
| Резерв изображения | `PlantReservation` | plants | Занятость пары (владелец, отпечаток) одной заявкой |
| Задание модерации | `ModerationJob` | moderation | Попытки автоматического распознавания растения |
| Турнир | `Tournament` | tournaments | PRIVATE-турнир или единственный GLOBAL |
| Приглашение | `Invitation` | tournaments | Приглашение пользователя в закрытый турнир и его заявка |
| Участие, участник | `TournamentEntry` | tournaments | Участие конкретного растения пользователя в турнире |
| Окно голосования, раунд | `VotingWindow` | tournaments | Интервал `[opensAt, closesAt)` с зафиксированным составом |
| Участник окна | `WindowParticipant` | tournaments | Участие entry в конкретном окне: счёт и итог |
| Голос | `Vote` | tournaments | LIKE/DISLIKE субъекта за участника окна |
| Субъект голосования | `VotingSubject` | tournaments | USER(userId) или GUEST(токен гостевой сессии) |
| Эпоха отбора | `QualificationEpoch` | tournaments | Период глобального отбора с фиксированным составом |
| Кластер, ячейка | `Cluster` / `ClusterSnapshot` | geo | Географическая группа участников эпохи |
| Лента | `Feed` | feed | Подборка карточек для голосования |
