# ADR-001: Классификатор растений — ONNX Runtime + MobileNetV2

Статус: принято (итерация 0, реализация — итерация 4).

## Контекст

Требуется автоматическая проверка наличия растения на изображении (раздел 6
требований). Проверка имени файла, MIME или случайный boolean не допускаются;
допустим HTTP inference-сервис или модель в JVM.

## Решение

- **ONNX Runtime 1.30.0** (pin, проверен на Maven Central 2026-09-23) — инференс
  в JVM, без внешнего сервиса.
- **Модель MobileNetV2** (ImageNet-1000 классов), файл модели закоммичен в репо —
  версия зафиксирована, воспроизводимость гарантирована.
- **Решение**: сумма вероятностей plant-классов ImageNet ≥ порога → APPROVED,
  иначе REJECTED. Порог конфигурируемый; значение по умолчанию фиксируется при
  реализации итерации 4 (после калибровки на эталонных изображениях).
- **Инференс вне DB-транзакции**: короткая транзакция захвата задания,
  вычисление вне транзакции, короткая транзакция применения результата
  с проверкой версии (раздел 12 требований).
- **Недоступность/ошибка модели** → PENDING + retry (`nextAttemptAt`), это
  техническая ошибка, а не REJECTED и не APPROVED.
- Детерминированный тестовый адаптер `PlantClassifier` — только в test/demo-профилях.

## Последствия

- Зависимость `com.microsoft.onnxruntime:onnxruntime:1.30.0` добавляется в итерации 4.
- Демонстрация inference на положительном и отрицательном изображении — критерий
  готовности итерации 9 (тег `inference`).
